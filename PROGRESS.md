## 6 · Alternative Comparator Design (COMP-ALT)

> **Relocation note (2026-07-30):** all of Luc's COMP-ALT files now live in a self-contained **`comparator_alt/`** folder (`schematic/`, `layout/`, `results/`), mirroring `comparator/` and `dac/` — nothing shares a directory with the primary StrongARM block anymore. Symbol references inside the moved schematics were updated to the new paths. ⚠️ `DESIGN_LOG.md`, referenced throughout this section, has **not been committed to the repo yet** — Luc still needs to push it.
>
> **Design-direction note (2026-07-28):** this block takes the *opposite* approach to COMP-5 on offset. COMP-5 treats comparator offset as a calibratable DC shift and does no upsizing; COMP-ALT reduces it in the analog domain with a **double-tail** topology (clocked dynamic preamp → StrongARM latch, Schinkel ISSCC 2007). Both are valid for a SAR — this one is the backup that also removes kickback into the cap-DAC top plate, which a bare StrongARM injects directly onto the node being measured. Full reasoning, verification history and tool/PDK gotchas are recorded in **[`DESIGN_LOG.md`](DESIGN_LOG.md)**.

| ID | Task | Owner | Status | Artifact |
|----|------|-------|--------|----------|
| COMP-ALT-1 | Alternative comparator topology (backup/comparison to the StrongARM latch) | Luc | 🟢 Complete | `DESIGN_LOG.md` — **double-tail** selected (dynamic preamp + StrongARM latch). Baseline StrongARM MC gave mean +2.6 mV, **σ = 36.9 mV** (N=100), matching the predicted √2·svt ≈ 35 mV → offset is **input-pair-Vth-dominated**. `A_VT ≈ 6.2 mV·µm` extracted from our own data (24.8 mV × √(0.22×0.28 µm²)) rather than assumed. Pelgrom's √area law then shows a direct-upsizing fix needs **~340× gate area** on the latch's speed-critical nodes — rejected, since those same devices set both the regeneration time constant and the comparator's input cap (which the DAC has to drive). A gain stage divides the latch's offset by A instead, moving the area burden onto a **speed-uncritical** preamp input pair. Dynamic (clocked-tail, capacitively-loaded) preamp chosen over a static one for **zero static current** — a static bias would burn current through all 8 bit-trials for a block needed ~100s of ps per trial. |
