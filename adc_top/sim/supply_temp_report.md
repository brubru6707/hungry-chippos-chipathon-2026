# ADC supply/temperature sweeps (INT-7 follow-up, 2026-07-31)

Reduced 21-code per-code sweeps (same trusted methodology/settings as
Gate 3/4: constant VIN at code centers, 0.05n max step, reltol=1e-4),
TT models, generated by `designs/scripts/gen_adc_sweep_vt.py`. Code
centers are VDD-ratiometric (the DAC reference is VDD). 84 runs total,
dirs `sweep_{v30,v36,tm40,t125}/` (decks regenerable; results below are
the checker outputs).

| Condition | Monotonic | Err band (nonzero codes) | Dead zone ends between codes | ≈ VIN bound |
|---|---|---|---|---|
| 3.0 V / 27 °C  | yes | 0 / −1 | 40 → 44 | 0.48–0.52 V |
| 3.6 V / 27 °C  | yes | 0 / −1 | 32 → 40 | 0.46–0.56 V |
| 3.3 V / −40 °C | yes | 0 / −1 | 44 → 48 | 0.57–0.62 V |
| 3.3 V / +125 °C| yes | 0 / −1 | 16 → 32 | 0.21–0.42 V |

**Verdict:** every condition is structurally identical to TT/27 °C/3.3 V —
monotonic, no missing codes among the sampled set, the same uniform −1
calibratable offset band above mid-range, and only the low-Vcm dead zone
moves. The dead zone tracks the NMOS threshold exactly as the MOS-corner
sweep found (worst here = cold, ending ≤ code 48 ⇒ ≈0.62 V), so the
quoted 0.65 V low bound holds across supply ±10% and −40..125 °C at TT
models.

**Residual caveat (documented, not run):** the cross-corner SS × −40 °C
was not simulated; both axes individually reach ≈0.62 V, so their
combination could push the true low bound slightly above the 0.62 V
guaranteed number — the 0.65 V *quoted* bound is the one with margin.
