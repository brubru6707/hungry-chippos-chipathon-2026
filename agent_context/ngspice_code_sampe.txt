Hi all,

Well, I had some trouble learning how to work with variables and vectors and ngspice - so here is a commented script, which performs some purely mathematical operations (there is no circuit defined whatsoever) - and demonstrates some basic usage of vectors and variables referencing, as well as linear interpolation between vectors.

Note that the the script first goes to demonstrate the linear interpolation, then resets the plot, and then shows additional basic examples. You could in principle also execute it command by command in interactive mode in ngspice - however the output of the script is also posted below for reference. (Its kinda big, but I think it demonstrates a lot of things n00bs with ngspice could find strange at first).

The linear interpolation part deals with the problem of how do you plot, if you have two vectors that cover the same x-range, however, are different in size? In the script, the smaller vector is "resampled" into a new version of the same size as the larger vector, with the values being linearly interpolated. The linear interpolation is as simple as it gets, and it looks kinda crappy for the default large vector size of 10 elements, and small size of 6 elements … however, the looks improve with increased number of elements, say large = 100 and small = 20 elements:



Well, I hope some may find this useful (though, I've noticed, Google at least doesn't seem to crawl keywords in SourceForge forums, which is rather unfortunate…)

Cheers!

Here is the script 'vec_manip.net':

* Schematics Netlist *
.control
echo ...........
* set color for postscript output
set hcopypscolor=1
* create new plot (collection of vectors)
set curplot = new
* some variables: larger num. of elements/samples (default 10), and smaller (default 6)
set NUML=10
set NUMS=6
* show what is in new plot
echo _____________ P_01
display 
echo
* create x axis (vector xx) - 10 points
* we do it here just to allocate it first:
* http://iecon02.us.es/ASIGN/DCSE_1IE/WinSpice_tutorial.pdf:
* "Note how the first vector brought in becomes the default scale. This is an important point to remember because all the other vectors are plotted in reference to the scale. However, even if this were not set properly, NUTMEG allows plots to specify the scale explicitly as shown below: 'asciiplot all vs input' ... "
* let xx = vector(10); 'vector' gives elements as 1,2,3,... - 'unitvec' gives 1,1,1,... 
let xx = vector({$NUML})
* show what is in the plot
* note the first plot automatically becomes [default scale]
echo _____________ P_02
display 
echo
* define twopi via set (stwopi) - it gets defined as string!
* so must add enclosing (), to force algebraic interpretation! 
* but that works only with 'let' - 'compose' cannot use stwopi!
* set sets values to variables
set stwopi=(2*pi)
* let sets values to vectors
* however, if this is first, it will become [default scale] !! 
let ltwopi=2*pi
* .... 
* only sltwopi - which demands a 'let' vector - will work in a compose command!! 
* "$&..." syntax from ngspice/ng-spice-rework/examples/control_structs/MonteCarlo.sp
set sltwopi="$&ltwopi"
echo _____________ P_03
print $stwopi ltwopi $sltwopi
* in the echo for ltwopi, we must have & as we refer to a vector
echo $stwopi $&ltwopi $sltwopi
echo 
* create x axis (vector xx) - going from 0 to 2pi, 10 points
* we could also use let as in: 
*~ let xx = vector(10)*($stwopi/10)
* but, here let's use compose for that 
compose xx start = 0 stop = {$sltwopi} lin = {$NUML}
* show what is in the plot
echo _____________ P_04
display 
echo
* define a type of vector called 'angle' in units 'rad' .. and assign it to xx
* http://newton.ex.ac.uk/teaching/CDHW/Electronics2/userguide/sec5.html
deftype v angle rad
settype angle xx
* show what is in the plot
* note the change of type from 'notype'
echo _____________ P_05
display 
echo
* create the output (y-axis) vector; lets say sine
* note yy becomes of type 'angle' here too!
let yy = sin(xx)
* show what is in the plot
echo _____________ P_06
display 
echo
* now let's create 'shorter' versions of xx and yy
compose xxs start = 0 stop = {$sltwopi} lin = {$NUMS}
settype angle xxs
* lets use cosine here
let yys = cos(xxs)
echo _____________ P_07
* printout all vectors so far:
print xx yy xxs yys
* notice even if xx and xxs have the same range, 
* they have different number of elements;
* and so a command like 
asciiplot yy yys
echo
* will not 'stretch' yys across the plot; 
* instead, both yy and yys will refer to 
* 'Index' as x-axis parameter! 
* so, we basically have to 'resample' yys 
* from current 6 samples to 10, in order to chart it
* together with yy! 
* there is a function for that, interpolate; however
*~ let yysi = interpolate(yys)
* will result here with 'Error: lengths don't match'
* 'linearize' will also fail: 'Error: can't get transient parameters from circuit'
echo _____________ P_08
* so we resample manually.. 
* syntax: ngspice/ng-spice-rework/examples/control_structs/repeat3.sp
let yysi = vector(length(xx))*0
let mainindex = 0
while mainindex < length(xx)
  let shortindex = 0
  while shortindex < length(xxs)
    if xxs[shortindex] >= xx[mainindex]
      break
    end
    let shortindex = shortindex + 1
  end
  if shortindex >= length(xxs) 
    let shortindex = length(xxs)-1 
  end
  echo mainindex "$&mainindex" "$&shortindex"
*  here we should have shortindex, copy to interpolated array
*   direct resample - just
*  let yysi[mainindex] = yys[shortindex]
*
*   crude linear interpolation
  if shortindex = length(xxs)-1
    let yysi[mainindex] = (xx[mainindex] - xxs[shortindex-1])*( (yys[shortindex]-yys[shortindex-1])/(xxs[shortindex]-xxs[shortindex-1]) ) + yys[shortindex-1]
  else
    let yysi[mainindex] = (xx[mainindex] - xxs[shortindex])*( (yys[shortindex+1]-yys[shortindex])/(xxs[shortindex+1]-xxs[shortindex]) ) + yys[shortindex]
  end
  let mainindex = mainindex + 1
end
echo _____________ P_09
* show what is in the plot
* notice, for some reason, 'mainindex < length(xx)' is a vector now?? 
display 
echo
* printout all vectors so far:
print xx yy xxs yys yysi
* plot the interpolated now:
asciiplot yy yysi
echo
* well, it is stretched, but quite ugly due to 
* really low number of points, and no interpolation.. 
* with interpolation looks a bit better.. and also with a larger number of samples
* plot the diagram 
hardcopy interplot.ps yy yysi
* some final notes;
* note that you cannot downsize a vector once 
* its has been defined, and its size specified: 
* yy was originally 10 ( NUML ) elements long
* try replacing it with 6 (NUMS) elements one:
* "left-hand expression is too small (need 100)"
let yy = vector({$NUMS})
* check it back - still NUML elements, which haven't been replaced
echo _____________ P_10
display yy 
print yy 
echo 
* note about redimensioning with 'reshape'..
* yy/xx are currently NUML = 10 long, i.e. 1 column 10 rows
* reshape can redim only where newwidth*newheight = NUML
* so NUMLxNUML being bigger than NUML, will clearly fail
* 'dimensions don't fit "yy" (total size = 10)'
echo _____________ P_11
echo ...+++
reshape yy xx [{$NUML},{$NUML}] 
echo ...+++
* however, for 10; 10,1 / 1,10 / 2,5 / 5,2 will work
reshape yy xx [10,1]
reshape yy xx [1,10]
reshape yy xx [5,2]
reshape yy xx [2,5]
echo ...+++
* show what is in the plot
* note the "dims = [2,5] " appearing for xx,yy
echo _____________ P_12
display 
echo
* the extra dimensions will be interpreted as parameters,
* which can be seen by repeating the plot
* note since yysi was not redim'd, it will still be graphed as before. 
* however yy will be shown in several parts.. 
*~ hardcopy interplot.ps yy yysi
* now that we have extra dimensions, we could use transpose, say:
echo _____________ P_13
transpose yy
* note after traspose "dims = [5,2] " for yy
display 
echo
* Finally, note there is no way to delete a vector;
* we can only delete a whole plot ! 
* as we created this plot with new, it is probably called 'unknown1'
destroy unknown1
* check it - show what is in the plot
echo _____________ P_14
display 
echo 
* we are in the "Constants" plot; 
* so we should again create a new one:
* create new plot (collection of vectors)
set curplot = new
* check it - show what is in the plot
echo _____________ P_15
display 
echo 
* just to show some final points:
* variable names which are already defined as 'Constants'
* cannot be used !
echo _____________ P_16
* print the old const value for c:
print c
* try to make 'c' a new vector
let c=vector(10)
* check it - show what is in the plot
display 
* dimension hasn't changed - but variable 'c' got reset to 0 !! 
print c
echo 
* also quite easy to extract subranges of vectors:
echo _____________ P_17
let uu=vector(5)
let ww=uu[2,4]
print uu ww
echo
* direct assignment :
echo _____________ P_18
* this gives a syntax error
let zz = [12,176,278]
* compose with 'values' statement works though
compose zz values 12 176 278
print zz
echo
* concatenation; probably through redim? 
echo _____________ P_19
let qq = vector(6)*0
reshape qq [2,3]
let qq[0] = ww
let qq[1] = zz
* print line show vector in a row.. 
print line qq
* show what is in the current plot
display 
echo
echo ...........
echo
.endc
