Mitch Bailey — 6/17/26, 7:12 PM
It is possible to use digital blocks in analog circuits.
If your LVS source for the digital block is gate-level verilog, be sure that the xschem symbol ports are in the same order as the verilog ports. The easiest way to do this is probably just edit the *.sym file.
If your analog layout is done in magic, be sure to read the gds for the digital block with the readonly option set.
You may need to use cif *hier write disable or cif *array write disable to prevent magic from adding layers to the digital blocks.
